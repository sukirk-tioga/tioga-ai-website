02 — The six disciplines

Qualify
Capability floors enforced at routing time — no agent absorbs a task class it hasn't been measured competent for.
Arbitrate
Cross-vendor AI spend compared on one defensible cost basis, even across non-fungible budget types.
Gate
Tiered autonomy with a hard human ceiling — propose-and-approve, never auto-applied to live configuration.
Probe
The same behavioral check run identically across every system in scope — live calls, not trusted dashboards.
Track
Findings live in an aging ledger — nothing clears without machine re-verification or explicit human resolve.
Review
The vendor/model estate is re-evaluated on a fixed cadence against pre-committed criteria.
